# Obsidian

Obsidian is the first reference skin for Eightfold Armoury: a dark, calm, high-contrast visual system for long, focused Harness sessions.

## Install

~~~bash
pnpm dsh eightfold skin add obsidian
pnpm dsh eightfold skin use obsidian
~~~

## Design intent

- near-black blue surfaces instead of flat black;
- cool blue focus and accent states;
- clear text hierarchy for dense developer interfaces;
- restrained radii, elevation, and motion;
- no executable code and no behavior changes.

The package is presentation-only. Its contract is defined by `eightfold.skin.json` and `theme.json`.
